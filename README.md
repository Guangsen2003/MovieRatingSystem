# Movie Rating System

## Project Description:

The Movie Rating System is a Java program that allows a user to enter five movies they recently watched and rate each movie from 1 to 10. The program stores the movie names and ratings in parallel arrays and calculates the user's average movie rating.​
The program uses several Java decision structures, including if-else statements, nested if statements, logical operators, a switch statement, and the conditional operator. It also validates user input to make sure every rating is between 1 and 10.​

## Features:

• Asks the user for their name​
• Accepts five movie names​
• Accepts and validates five ratings from 1 to 10​
• Stores movies and ratings in parallel arrays​
• Calculates the average movie rating​
• Classifies the user's overall movie preferences​
• Detects ratings of 10 and very low ratings​
• Checks whether the user consistently gives high ratings​
• Uses a switch statement for genre preferences​
• Gives a movie recommendation based on the selected genre​

## Reflection:
A nested if statement places one if statement inside another, while an if-else statement chooses between different conditions or outcomes. A switch statement can make code easier to read when there are several specific choices, such as movie genres, instead of writing many separate if statements. The conditional operator simplifies small decisions because it can choose between two values using a single expression instead of a full if-else statement. Short-circuit evaluation means Java may stop checking a logical expression once the result is already known, such as when the first condition of an && expression is false or the first condition of an || expression is true. This can make the program more efficient and can also prevent unnecessary conditions from being evaluated.
